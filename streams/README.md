# Incident 01 recovery stream

[incident-01.bin](incident-01.bin) 是实地恢复推导出的原始密钥流，由数据所有者授权公开。[incident-01.json](incident-01.json) 记录长度、密钥流的 SHA-256，以及适用的 265 字节标记的 SHA-256。两个文件需配套使用。

## 如何得到并验证

1. 从旧聊天附件找回两份原件，确认较大文件的首、中、尾三段使用相同的 65,536 字节密钥流。
2. 对比小文件时，发现同一标记在文件开头。先跳过 265 字节，再与原件异或，得到一段更长的密钥流。
3. 从本机应用缓存和备份中找到更长的精确副本。最后从一个已恢复的压缩包中提取原件，将可验证的密钥流延长到 2,063,922 字节。
4. 发布前使用附带的密钥流重建了三个有独立原件的目标，覆盖两种布局，恢复件均与对应原件逐字节一致。

这份密钥流只适用于标记匹配、符合已验证布局的文件。公开目录不包含实际原件、加密样本或标记原始字节。用于练习的原件和加密件位于 [samples](../samples/)。
